# Shopify Liquid theme conversion for LIVOARA

Convert the current LIVOARA Lovable storefront into an upload-ready Shopify theme while keeping the same visual direction, layout, copy style, and customer experience.

## What will be built

- A complete Shopify theme folder, packaged as a `.zip` ready for Shopify upload.
- Liquid templates for:
  - Home page
  - Product page
  - Collection page
  - Cart page / cart drawer support
  - Search
  - Customer account pages
  - Standard policy/content pages
- Shopify-native product, collection, cart, checkout, customer account, and menu connections.
- Editable Shopify settings so the store owner can manage text, images, videos, buttons, categories, and feature blocks from the Shopify theme editor.
- LIVOARA styling migrated into theme CSS so the look remains consistent with the existing Lovable site.

## Scope details

- Use Shopify Liquid and Shopify standard objects such as `product`, `collection`, `cart`, `customer`, `routes`, `linklists`, and `shop`.
- Use Shopify cart forms and checkout flow instead of the current app cart code.
- Use Shopify product variants for the 1 / 2 / 3 piece offers.
- Keep sample feedback clearly labelled; no fake ratings or deceptive review counts.
- Use theme settings for images and videos because Shopify themes cannot directly use Lovable-hosted local imports.

## Deliverable

- A clean theme source folder under the project for maintenance.
- A zipped copy in Files named for Shopify upload.
- A short note listing which assets/settings the owner should replace inside Shopify after upload.
