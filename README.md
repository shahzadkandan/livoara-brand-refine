# Livoara Brand Refresh

Update the LIVOARA website using the attached Livoara reference screenshots.

IMPORTANT — HERO BANNER:

Use the attached Livoara hero banner image as the EXACT homepage hero image.

DO NOT generate, replace, redesign, or create another hero image.

The hero banner should appear prominently as a large full-width responsive banner on the Home page, similar to the reference layout.

HERO CONTENT:

- Use the attached banner exactly as provided

- Elegant LIVOARA typography

- Premium warm blush/cream color palette

- "Made for every moment." headline

- Short supporting text

- "Shop Now →" CTA

- Maintain the same luxury editorial aesthetic

- On mobile, crop/position the image intelligently so the product remains clearly visible

IMPORTANT PRODUCT RULE:

Livoara currently has ONLY ONE PRODUCT.

Do NOT create multiple products or fake collections.

Use this same Livoara product throughout the website.

HOME PAGE:

Keep the reference-inspired sections:

- Hero Banner

- Newsletter

- Footer

Keep the exact Livoara visual identity:

- Warm blush/cream colors

https://celoriva.com/products/celoriva-knee-massager

Do NOT copy Celoriva's branding, colors, images, text, or product.

REQUIRED PAGES:

1. About Us

Do not invent product information, prices, reviews, specifications, shipping times, or business claims. Use editable placeholders where necessary.

Make the entire website fully responsive, especially mobile.

FINAL GOAL:

The website must look like a premium LIVOARA brand, with the ATTACHED HERO BANNER as the main homepage visual — not a generic template and not a Celoriva clone.
